# Pi Arm 网页控制台

本目录包含前端操作说明和静态资源。整体安装、服务启动、端口、CAN 与版本恢复见 [根 README](../README.md)。默认通过 `http://树莓派IP:8000/control.html` 打开，点击“连接”；不自动使能、回零或执行运动。三维模型必须通过 HTTP 加载。

## 界面与连接

工作台包含三维模型、任务结果、六关节与末端状态、运动目标、预设姿态和电机管理。点位示教用于存取目标和重复定位测试；运行记录显示请求与结果。切换“开发者”视图可看诊断和方向测试，它只是界面偏好，不是登录或权限认证。

连接后核对 real/mock、正常/只读/commissioning、标定 ID、六轴反馈新鲜度和控制许可。FAULT 或标定无效时仍应能查看原始数据。灰色模型表示离线参考或最后有效姿态，不代表当前实机；网页状态超过 1.5 s 未更新会关闭新运动入口。

顶部“停止运动”是软件停止请求，不是物理急停。普通轨迹断开网页后可能继续到目标；多客户端没有独占控制锁，测试时使用一个控制页面。

## 坐标、反馈与速度

- J1–J6 是主动关节相对转角，顺序为 joint_01、joint_02、joint_04、joint_05、joint_06、joint_09。
- “输出轴”指减速器输出端相对模型零位的角，已包含标定偏移，不是电机协议角；腕部 CAN4 → J5、CAN5 → J4。
- XYZ 为 base_link 下 tool0 法兰中心，单位 mm；RX/RY/RZ 为固定轴 RPY，单位 °，旋转 `Rz(yaw) Ry(pitch) Rx(roll)`。当前没有工具偏置。
- “各关节坐标系相对 base_link 的位姿”是 URDF 子坐标系的 XYZ/RPY，不是另一组可直接下发的关节转角；RPY 在 pitch 接近 ±90° 时有奇异性。
- 模型与坐标显示来自编码器/绳索反解和同帧 FK，不能作为独立实物角度或末端精度测量。

角速度默认 **5°/s**、最高 **10°/s**。普通运动同时受各自的关节/姿态速度和“运动目标与参数 → 输出轴速度上限”约束；修改对下一次任务生效，不是实时速度倍率。

回零/打包的关节速度在“预设姿态”区域调整；重复测试使用其面板内单独的速度快照。绳索耦合会使输出轴比关节走得更远：打包到零位时第 3 输出轴约走 449.2°，输出轴限速 5°/s 需要约 90 s，即使关节框设为 10°/s 也不会更快。

点位与常用位置数据显示最多三位小数；ROS/CAN 和磁盘原始存档保持内部精度。三位小数是显示精度，不代表物理测量精度。

## 运动与预览

| 操作 | 输入与行为 |
| --- | --- |
| 单关节 / 多关节 | 单轴目标或六关节目标，正常 DirectMove 链路，其他轴保持；不是裸电机协议运动 |
| 输出轴目标 | 六个模型输出角，先绳索反解，再检查关节/输出限位与执行 |
| 笛卡尔控制 | 仅输入 base 下 tool0 的 XYZ/RPY，使用 Pilz LIN；关节框不会混入此目标 |
| 打包 / 零位 | 打包目标来自当前接受的标定，零位目标为六关节 0°；不会重设电机零点 |
| 输出轴反解 / 关节路径 | 返回关节目标和与 DirectMove 相同的线性插值显示；不经过 MoveIt 避障 |
| 笛卡尔 IK | 当前反馈作种子求端点解并检查模型端点碰撞；有解不代表整条直线可达 |
| LIN 路径规划 | 与实际 MoveL 使用相同管线，只规划不执行 |

预览不使能、不获取运动租约，也不发送执行轨迹。真正运动仍由用户点击对应按钮，从最新反馈重新生成。DirectMove/输出轴/预设姿态不保证末端直线，也不进行 MoveIt 避障。

J2/J3 起点和反馈可用 3° 容差，目标始终使用标准限位；容差带起点可能先过渡到最近标准边界。正常到位需后端核验每轴误差、静止和连续稳定，默认 0.2° / 0.5 s，不以“请求已接受”或“不动了”作为完成。

### 三维模型与拖动

模型 X 红/Y 绿/Z 蓝，Z 向上、内部米制；正视相机位于基座 −Y 侧，侧视位于 +X，俯视位于 +Z。相机旋转不改变坐标定义。反馈超标准限位会提示，显示不偷偷裁剪实际解算角。

关节滑块和模型拖动默认只更新目标预览。选择连杆/J1–J6 后，将鼠标操作切为“拖动关节”，左右拖动改变所选角度；不是末端六自由度拖拽手柄。

开启“松手执行”后，每个完整手势至多提交一个单关节绝对目标，沿用速度和正常运动门禁。Esc、失焦、后台、切换视图、停止或反馈失效会取消手势；重新连接不保留勾选。开始重复测试会关闭松手执行。

青绿色模型显示目标，橙线显示 tool0 路径。路径回放压缩至约 10 秒，显示的估计轨迹时长才是时间参考；回放不是实机执行。目标/速度编辑、起点变化、开始运动或状态过期会使旧预览失效。

只读和 commissioning 仅有姿态显示，不提供正常 manager 的 IK/LIN 服务。WebGL 或模型资源失败不应影响数值诊断和软件停止。

## 到位保持与实机拖拽示教

正常运动到位后保留位置闭环，不发送停止来释放力矩。手动搬动需在总体控制点击“进入拖拽示教”，先支撑机械臂；这是停止位置闭环，不是重力补偿或力控拖动。

进入/退出均要求无运动任务、新鲜连续静止反馈。示教期间禁止普通运动和直接使能，断开网页不会自动重新上力。示教使用 0x81，不使用可能清除圈数的 0x80；电机显示使能不等于仍在位置保持。

拖动后静止即可记录反馈点位。点击“结束示教并保持当前位置”，后端捕获当前协议角，以 1°/s 输出轴上限建立当前位置保持并核验回包/反馈，不使用 0x88 恢复旧目标。这一 1°/s 只用于示教退出建立保持，不是普通运动限速。

若反馈超出允许范围，先在支撑状态下移回有效范围再结束示教；失败时查看原因，不自动重新使能或清零。

## 点位示教与备份

点位类型为六关节（°）或笛卡尔（mm/°）。来源：

1. **手动输入**：选择类型、六个数值、名称和备注后保存。
2. **当前实机反馈**：静止且标定/运动学有效时记录，由服务端取同帧数据，不用浏览器旧值冒充实测；允许未使能或只读时录入。
3. **模型预览目标**：关闭松手执行，拖动/计算预览后保存完整六关节目标；不是实测反馈。

保存不代表目标已经通过限位、IK 或路径检查。“加载到运动表单”只填目标，需另行检查并点击运动。普通加载会拒绝硬件类型、模型/关节顺序不匹配；标定变化提示重新核验。

点位保存在树莓派，默认 `~/.local/share/pi_arm/points-real.json` / `points-mock.json`，跨刷新/服务重启保留。可通过启动参数 `points_file` 更改。最多 500 个、2 MiB，名称唯一；库版本冲突时刷新后重试，损坏文件保留原内容并报错。

点位记录携带来源、时间、单位/坐标系、模型哈希、标定 ID；反馈来源额外保留原始电机协议角与 ROS 时间。支持导出 JSON、删除。恢复备份时停止服务后复制到对应点位文件路径；切换 Git 分支不会恢复点位库。

## 重复定位测试

入口为“点位示教 → 重复定位测试”。选择已保存的起始点 A 与目标点 B，两点必须同类型、不同目标，且与当前硬件、模型、标定、坐标系/关节顺序一致。

1. 设置循环次数（1–1000，默认 10）、每次到点等待（0–3600 s，默认 3）。
2. 设置关节/姿态速度及输出轴上限（默认 5°/s、最高 10°/s）；笛卡尔点另有直线速度，默认 5 mm/s。
3. 点击“开始循环运动”。每轮 **A → 到位等待 → B → 到位等待并记录**，初始到 A 包含在第一轮内。完成最后一轮停在 B 保持。
4. “停止测试与运动”取消后续循环并请求停止；结束或中止后导出 JSON/CSV，再开始新一组或刷新页面。

等待从匹配任务编号的成功、`arrival_state=reached` 与六电机新鲜静止反馈之后计时，是每次到点后的等待，不是固定发令周期。完整一轮还包含两段运动和反馈延迟。起始/目标参数在开始时冻结，测试过程中锁定输入，工作台速度框不会改变本组测试。

关节点走 DirectMove，笛卡尔点走 LIN；本面板线加速度固定 10 mm/s²，姿态加速度请求值 10°/s²，实际依现有 Pilz 处理。无解、超限、任务取消/失败、反馈过期、失能、示教、模型或标定变化均中止，不自动重试。单段前端等待上限 30 分钟，后端超时仍独立生效；到点等待单独计时。

测试需保持网页前台。进入后台、关闭/刷新或断连会取消后续循环并尝试停止；重新连接不会续跑。停止请求未送达时当前段可能继续到位。其他客户端任务编号改变也会中止，但这不是跨客户端独占锁。

### 测试记录含义

每轮在 B 等待结束时记录同帧关节反馈、base 下 tool0 XYZ/RPY、原始协议角、目标角、任务号、浏览器 UTC 时间、容差与到位状态。

- `verification_error_joint_angles_deg`：后端最后一次到位核验保存的目标−反馈误差。
- `sampled_error_joint_angles_deg`：等待结束时用目标减去当前反馈，单独反映采样时误差。
- JSON 包含 A/B 快照、速度/等待/次数、标定/模型编号、结果及中止原因；可以中途导出当前快照。
- CSV 每行一个目标点样本，数值最多三位小数，用轮次/时间对照外部量具。
- 页面 XYZ 极差是解算位置各轴最大值−最小值，不是标准重复定位精度，也不包含独立轨迹跟踪测量。

记录只在当前页面内存，刷新、关闭或开始新测试前导出。真实末端精度需要外部测量，不能只用模型反馈证明。

## 故障恢复与诊断

“电机故障恢复”可选 CAN1–6：先检查故障原因，静止并支撑后清错（0x9B），必要时重启所选电机（0x07）。FAULT/标定无效时可依据原始新鲜静止反馈开放；断线、总线故障或持续欠压/过热不能靠按钮自动消除。

重启无 ACK，成功表示发送后反馈恢复、无错且确认关闭；电机不会自动使能或恢复轨迹。重启前后输出轴参考变化超过 0.2° 或核验失败会锁定 `REBOOT_REFERENCE_UNVERIFIED`，需人工核对姿态/参考。重启 ROS 进程不能证明参考已修复。ROM 标零后仍使用 [人工重新上电流程](../src/pi_arm_hardware/config/README.md)。

开发诊断可导出原始协议角、原始/模型输出角、软件偏移、关节角、错误/标定。运动学故障不一定是电机故障，保留实际数据后区分零偏、方向、几何与机械回差。

## 方向测试

仅 `--commissioning` 服务开放。电机测试按协议正方向，步长对应输出轴角幅度，单步最大 5°、距首次测试起点 ±30°；不是按全局输出轴正方向解释按钮。关节测试单步最大 0.5°，会带动必要的耦合电机，输出轴行程仍受调试范围检查。

测试角速度默认 5°/s、上限 10°/s；过低且协议无法表示的速度会拒绝。浏览器持续发送测试心跳，超时停止；这与普通轨迹断线策略不同。记录命令、协议角变化、实物方向和模型方向，再导出观察数据。无需为看诊断而盲目放宽正常关节目标限位。

| `assets/interactive.js` | 手势、后端预览与失效管理 |

| [vendor/README.md](vendor/README.md) | 固定版本三维依赖、许可证与重建方法 |
| `model/` | 构建/启动从源 URDF 导出的资源，不提交 Git |

静态页面无需 Node/npm 构建，运行不依赖 CDN。Three.js 0.180.0 / URDF Loader 0.12.6 本地打包，首次模型资源约 15 MiB。需要支持 WebGL2、DecompressionStream 的浏览器；渲染不可用时保留数值控制。

控制、点位、循环脚本及样式使用相同发布版本的 `?v=`。修改这些互相依赖资源时一并更新 HTML 版本参数，避免新页面搭配旧脚本。典型症状是点位卡片正常而下拉框为空；刷新列表或重新打开更新页面，原点位不需删除。

前端测试分离线拦截 WebSocket 和隔离 mock 两类，入口及依赖见 [scripts/README.md](../scripts/README.md)。不要用实机地址运行运动自动化测试。

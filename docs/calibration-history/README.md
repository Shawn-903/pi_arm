# 标定历史

当前方向配置配套标定为 `src/pi_arm_hardware/config/pack_reference_calibration.R07.recorded.yaml`。
从 R06 切换须在启动参数中明确指定 R07；旧进程不会自动重新加载。
本目录保留测量、方向试验及快照，供追溯与回退，不作为运行时自动选择列表。

| 版本 | 含义 |
| --- | --- |
| R02 | ROM 重新置零之前的参考，不能用于当前零点 |
| R03 | ROM 置零并重新上电后的打包原始测量，保留候选和接受记录 |
| R04 | 基于 R03 测量反转绳索输出 3、4 |
| R05 | 输出 1、2 反向试验，已由操作者撤销 |
| R06（源码配置目录） | 输出 3、4、6 反向，原阶段基线 |
| R07（源码配置目录） | 在 R06 基础上绑定操作者修改的输出 5 反向；测量及 ROM 参考不变 |

approved 表示当时接受该参考用于测试，不能跨 ROM 零点、机械结构或方向配置复用。
绑定必须匹配对应模型快照与当前执行器映射。原始测量和历史文件不随清理过程删除。

## R07 配置不匹配修复

现场网页诊断为 `CALIBRATION_INVALID`，实际原因是
`configuration_fingerprint mismatch: expected fnv1a64:13f630c1b4f4b100`。
R06 的指纹为 `fnv1a64:f75d418ecdb20919`，对应 `motor_05: +1`；当前模型为 `motor_05: -1`。
差异核查确认只有 output_directions 改变，几何、限位、减速比和安装映射没有变化。

使用 `scripts/rebind_cable_directions.py` 生成 R07 与对应模型快照，保留 R06 原文件。
打包关节实测角与打包原始输出角逐项不变；启动时由加载器按新模型重新计算软件零偏。
实际 C++ 加载器验证：R06 在当前模型下被拒绝，R07 通过；打包姿态往返误差最大
`4.44e-16 rad`。这些是离线一致性检查，不代表新的实测标定，也不证明方向的物理正确性。

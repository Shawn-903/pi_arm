## 本轮明确授权与实现

操作者要求起点使用反馈容差、下发目标使用标准限位，启动整臂轨迹控制器，增加输出轴目标，输出轴限速默认 5°/s 且可在网页调整。笛卡尔实机运动由操作者通过网页发起，助手不直接执行。

正常控制统一经过网页 → WebSocket → manager → joint_trajectory_controller → RealBackend → CAN。单独的 commissioning 原始电机方向测试仍保留为独立启动模式，不与正常控制同时占用 CAN。

| 功能 | 正常控制行为 |
| --- | --- |
| 关节控制 | DirectMove 支持单关节及六关节目标 |
| 输出轴目标 | `output_move` 输入六个模型输出轴角，单位 °；按规定正方向和模型零位定义，绳索反解及标准关节目标检查后进入 DirectMove |
| 打包/零位 | 已接入 DirectMove，打包目标来自当前指定的 R06（沿用 R03 测量，第 6 轴方向待测试）；预设关节速度已调整为 1°/s，同时受网页输出轴上限约束 |
| 笛卡尔 | `base_link` 下的 `tool0`，Pilz LIN 规划；经同一运动授权、轨迹控制和停止流程执行 |
| 速度设置 | 网页 `output_speed_limit` 单位 °/s，默认 5；下一条运动生效，执行中修改不改变已接受任务 |

输出轴目标控制保证终点输出角，实际采用关节轨迹到达该终点，不声称各输出轴同时匀速或按输出空间直线插补。

## 起点容差与下发边界

J2（joint_02）标准范围 ±100.7°，反馈/起点范围 ±103.7°；第 3 主动关节（joint_04）标准范围 ±85.6°，反馈/起点范围 ±88.6°。其他关节保持原范围。

起点检查保留实测反馈的反解值，不将显示值截断。起点位于容差区时，未选关节保持目标取最近标准边界；目标仍需通过标准限位。硬件记录本次授权时的起点包络，JTC 从该起点插值的初始过渡可以被接受，但传到电机前的关节目标投影到标准范围内。超出该起点包络、反馈容差或数学定义域仍拒绝。

MoveIt 从上述合法边界开始规划；若实际反馈尚在容差区，进入直线段前可能有边界过渡。网页明确显示这项行为，不能将过渡段当作严格笛卡尔直线。

## 限速和执行生命周期

各运动 Action 新增 `max_output_velocity`（rad/s，零表示默认 5°/s），DirectMove 新增 `output_space`，内部 SetMotionArmed 服务携带每次授权的输出轴上限。接口改变后需要重建并重启相关 ROS 节点。

轨迹以位置路点执行线性关节插值，避免样条在路点之间越界。绳索模型零位雅可比的绝对值可界定线性段的输出轴速度，时长按各减速比下实际可编码的速度上限重新计算。A4 速度字段作为上限向下取整，且不发送零值；采样位置决定轨迹进度，避免把连续速度向下取整造成持续跟随落后。网页全局上限最低为 1/6°/s，来自当前 6 倍减速比的协议分辨率。

DirectMove、输出轴目标、预设、MoveJ、MoveJs 和 MoveL 共享运动授权和停止确认。控制器启动和空闲不获得运动授权，不发送旧保持目标。完成、停止、取消或异常释放本次租约；释放使用本次任务 ID，避免影响后续任务。

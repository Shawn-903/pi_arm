## 尚待实测或开发解决

- 腕部大角度总弯曲与实机对应尚未完成标定；当前为 33.94 mm，不再使用已撤销的 67.88 mm 试验值。核验路径见 [模型诊断](../src/pi_arm_transmission/README.md#腕部实机核验)。
- 关节反馈由编码器和绳索模型反解。模型正逆一致、mock/vcan 到位都不能证明绳索弹性、回差、负载下保持力矩或真实末端精度。
- 重复定位功能记录目标点反馈，不采集外部量具、不实现连续轨迹跟踪精度评估；XYZ 解算极差不是标准重复定位精度指标。
- 没有用户鉴权、TLS 或跨网页独占控制锁；使用者/开发者视图是显示偏好。控制页面应部署在可信隔离网络。
- 普通运动缺少浏览器断连自动停止机制；重复循环仅能取消后续段并尝试软件停止。commissioning 的心跳保护不适用于普通轨迹。
- 曾观察到系统 MoveIt `move_group` 在 SIGINT 退出时段错误，尚未确认修复。记录退出故障与运动执行结果时应区分，后续需独立复现。
- ROM 写零 ACK 不能单独证明重上电后的多圈角已归零。当前保留人工完整断电/上电与静止反馈复核流程；不以网页故障重启替代标零后的上电确认。

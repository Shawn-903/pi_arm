现场补充：腕部弯曲较大时，模型与实物明显不一致。操作者否定通过更改腕部参数来修正。

CAN4 → J5、CAN5 → J4。5°/s 默认速度、10°/s 上限和网页调速功能保留。
服务保持停止，没有执行新的运动、置零或示教切换。

## 已确认的软件关系

- CAN4/5 的协议角与输出轴角比例为 6，安装方向均为 -1。
  原始协议角除以有符号比例，再加打包参考计算的软件零偏，得到模型输出轴角。
- 设 `phi4,phi5` 为加过零偏的模型输出轴角、`q2` 为主动 J2 角（全部为 rad），
  当前通道交换后的反解为：

  ```text
  a = 33.94 / 16.25
  b = 28.5 / 16.25
  J4 = asin(( phi5 - b*q2) / a)
  J5 = asin((-phi4 - b*q2) / a)
  ```

  公式显示：当前两路仅考虑自身非线性和 J2 线性补偿，没有 J4/J5 交叉项。
  缺少交叉项是不是错误，需要实际绳路几何或分轴数据才能确定。
- 网页将六个主动关节角按名称送入 URDF，仅进行一次角度转弧度。
  模型使用 `joint_07 = joint_06`、`joint_08 = -joint_05` 随动。
  正负号包含各自局部轴的定义，不应直接按符号判断物理弯曲是否抵消。
- 仅改变一个腕部主动关节时，模型中的腕部总弯曲约为主动关节角的两倍。
  两轴同时转动时，三维旋转不能用各轴角度简单相加。
  从 URDF 正运动学计算前臂 link_04 的 +X 轴与 tool0 的 +Z 法向夹角：

  | J4 | J5 | 模型腕部总弯曲 |
  | --- | --- | --- |
  | 10° | 0° | 20.000° |
  | 0° | 10° | 20.001° |
  | 10° | 10° | 28.213° |
  | 20° | 20° | 55.983° |
  | 30° | 30° | 82.820° |

  这验证的是模型假设，不能证明实物遵循该假设。

## 为什么不能靠倍增半径解决

参数加倍后，同一反馈变成 `q_new=asin(sin(q_old)/2)`，并非 `q_old/2`。
假设原模型的总弯曲恰好为实机两倍，实机总弯曲为 10°、30°、60°时，
加倍参数后的模型会分别显示约 9.962°、28.955°、51.318°。
这是条件计算，不是对现场实际传动关系的确认；它说明小角度接近、大角度失配
本身不能证明加倍后的参数或原公式正确。

## 分层排查与判别

1. **参考与测量方式。** 使用 R08；在网页诊断中确认标定 ID、反馈新鲜度和运动学有效。
   以实际前臂与法兰法向之间的夹角作为总弯曲，不把 base_link 下的 RX/RY/RZ
   当作腕部角；截图中的透视投影角也不能直接当作三维夹角。
   每组记录开始和回到起点时都保存反馈，观察零偏是否改变。
2. **先分轴，后组合。** 拖拽示教中保持 J1/J2/J3/J6 和另一个腕部自由度尽量不动，
   分别采集 J4、J5 的零附近、小、中、较大弯曲及回程；只在已确认的可动范围内取点。
   两个腕部模型轴并不等于屏幕前后/左右方向，前后拖动本身可能同时改变两路。
   单轴均吻合、组合不吻合，优先检查交叉绳路和闭环机构约束。
3. **验证铰链随动。** 同时观察腕部近端、中间连接件和远端的相对角，核查配对铰链
   在单轴、双轴弯曲时是否都保持模型规定的等幅关系。
   若近端角已经吻合、远端总弯曲不吻合，优先检查 URDF 的随动关系、局部轴、零位变换。
   不凭整段姿态就删除 mimic 或改成 0.5。
4. **验证协议比例。** 在可直接观察输出轴时做标记，比较同一段运动的协议角增量
   和实测输出轴角增量。当前 CAN4/5 预期 `abs(delta_protocol/delta_output)=6`。
   用增量排除软件零偏；不能用绳索反解出来的角作为这一步的独立测量。
5. **验证 J2 补偿与机械回差。** 腕部相对前臂保持同一姿态，改变 J2 后比较腕部反馈；
   若随 J2 漂移，检查导向半径/耦合符号/绕线路径。相同姿态分别从正反方向接近，
   若反馈不一致、回零不一致或随负载改变，则检查松绳、回差、绳索伸长和卷绕有效半径。
   只在较大角度失配，而重复性良好，更应检查非线性绳长公式和机构约束。

## 每个采样点保存什么

使用网页现有「导出诊断」保存完整 JSON（包含原始协议角、软件零偏、模型输出角、
六关节角、标定 ID）；同时独立记录实机总弯曲角、弯曲方向、近端/远端铰链角（能测则测）、
接近方向和负载。以相同编号配对实物测量与 JSON。

最小起步数据：一条尽量单轴的腕部运动，起点、小角度、中角度、较大角度、回到起点，
共五组配对记录。先定位比例、非线性、耦合或回差中的哪一类，再修改对应模型。
旧 R09 点位保存的是旧模型解算角，不能直接作为恢复 R08 后的实物参考。

# 点位示教与坐标显示计划

基线：`ab55fbe`。保留操作者当前第五轴方向及预设速度修改，不在本轮提交中改写。

1. 点位库：树莓派端原子持久化，关节/笛卡尔两种类型，名称与备注；手动目标、实机反馈、网页拖拽目标录入。
   加载只填入对应表单，使用原控制链显式执行。保存反馈要求新鲜、运动学有效且静止，允许电机关闭时记录。
   保存坐标系、单位、模型标识、标定 ID、数据来源及时间；提供导出和删除，跨模型或标定变化明确提示。
2. 表单拆分：六关节输入独立于 base_link → tool0 的 XYZ/RPY 输入；分别有速度参数、读取反馈与执行按钮。
   复用 DirectMove / MoveL 及现有停止、速度限制、预览和运动门禁。
3. 坐标反馈：同一 URDF 正运动学计算每个主动关节子坐标系相对 base_link 的 XYZ、RPY，保留四元数供数据使用。
   反馈无效或过期时不显示可用值，明确与关节相对转角的区别。
4. 验证：持久化/损坏文件/并发版本/非法数据/只读录入门禁、独立 FK 对照、离线网页表单路由和 mock 完整链路。
   不执行实机运动或自动解除力矩；现场搬动机械臂由操作者决定并支撑。

本轮为重复定位及轨迹测试提供点位基础，不将编码器推算值宣称为独立实测精度。

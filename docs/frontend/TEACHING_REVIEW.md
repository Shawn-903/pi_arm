# 点位示教、运动表单与 base 位姿 · 2026-09-17

基线 `ab55fbe`；分支 `feature/teaching-points-and-base-frames`。
本轮没有执行实机运动、关闭实机电机或重启实机服务。

## 点位库

导航栏进入「点位示教」。支持两种点位类型：

- 六关节点位：J1–J6 相对关节角，单位 °，加载到六关节运动表单。
- 笛卡尔点位：base_link 下的 tool0 法兰中心 XYZ / RPY，单位 mm / °，加载到笛卡尔直线表单。

三种录入来源：

1. **手动输入**：选类型、填写六个值、名称及备注，点击保存。
2. **实机反馈示教**：由操作者支撑并搬动实机，静止后点击「记录当前实机反馈」。
   读取服务端同一帧的角度与正运动学结果，不采用浏览器缓存作为实测值。
   允许电机关闭、正常控制或只读监测时记录；要求标定和解算有效、反馈新鲜、无故障及运动任务。
   本功能不提供重力补偿/力控拖动，不自动关闭电机；需要手动搬动时由操作者负责支撑与断使能。
3. **模型预览示教**：保持「松手执行」关闭，在工作台拖动模型或滑块，回到点位示教保存模型目标。
   保存完整的六轴预览终点，不使用其他输入框的残留值，也不将模型目标标记为实机测量。
   若预览失效，请重新拖动或计算。该方式依赖三维模型与正常控制模式的预览能力。

「加载到运动表单」仅填入对应目标，关闭松手执行并撤销旧预览。检查目标、速度和路径后，另行点击运动按钮。
保存不代表点位已通过关节限位、IK 或路径检查；执行仍由现有 manager、MoveIt/JTC 和 CAN 门禁核验。

点位跨刷新、浏览器与服务重启保留。默认文件：

```text
/home/cr/.local/share/pi_arm/points-real.json
/home/cr/.local/share/pi_arm/points-mock.json
```

自定义位置：启动命令追加 `points_file:=/绝对路径/points.json`。正常、只读和方向测试入口都支持。
实机与 mock 默认分库；网页拒绝加载硬件类型、URDF 模型版本或关节顺序不匹配的点位。
标定 ID 改变会显示复核提示，不能假定旧关节点位仍对应原来的物理位置。

记录包含名称、备注、创建时间、来源、六关节/末端目标、四元数、坐标系、单位、模型哈希和标定 ID；
反馈示教额外保存原始协议角及 ROS 反馈时间。支持 JSON 导出和删除。
最多 500 个点位、2 MiB；名称不能重复。文件锁、库版本检查、临时文件 fsync 和原子替换防止并发覆盖。
损坏的文件会报错并保留原文件，不自动清空。导出文件可在停止服务后复制回指定 `points_file` 路径恢复。

## 运动输入与坐标

原混合多关节面板拆为两个独立页签：

- 「多关节控制」只显示六关节角与关节速度，发送 `move` / DirectMove。
- 「笛卡尔控制」只显示 XYZ/RPY 与直线/角速度参数，发送 `movel` / MoveL。

两个面板各有读取当前反馈和执行按钮。全局输出轴限速、停止、任务互斥和到位检查继续生效。

工作台新增「各关节坐标系相对 base_link 的位姿」：
六个主动关节对应的 URDF 子坐标系（link_01、link_02、link_04、link_05、link_06、link_09）
的 XYZ / Roll / Pitch / Yaw。这里显示的是坐标系姿态，原有关节相对转角仍单独显示。
RPY 使用固定轴 XYZ，旋转矩阵 `Rz(yaw) Ry(pitch) Rx(roll)`；欧拉角在 ±90° pitch 附近存在奇异性。

后端直接使用同一 URDF（包含三个 mimic 随动关节）和同一帧关节反馈计算这些位姿及 tool0 位姿，
不依赖可能来自另一时刻的 TF 缓存。掉线、过期或解算无效时隐藏当前数值。
这些值来自编码器和绳索模型，不能作为独立的物理末端测量。

## 用于重复定位与轨迹测试

保存接近点 A、测量点 B（及其他轨迹端点），按一致的速度和接近方向加载、预览并执行。
到达后等待任务报告「到位已核验」，记录测量数据；重复相同顺序。笛卡尔两点间的路径可用 LIN 预览与执行。
本轮提供点位存取与单次执行基础；不自动循环执行，不自动采集外部仪器，也不计算重复定位或轨迹精度指标。
物理重复精度需要独立测量；编码器 FK 可用于内部诊断，无法单独识别绳索弹性和机械间隙引入的末端误差。

## 启动与现场确认

本轮已编译到工作区。按原方式手动启动，浏览器强制刷新：

```bash
cd /home/cr/pi_arm
bash scripts/start_web.sh \
  hardware_type:=real can_interface:=can0 allow_real_control:=true \
  calibration_file:=/home/cr/pi_arm/src/pi_arm_hardware/config/pack_reference_calibration.R06.recorded.yaml
```

现场先记录一个已知姿态，核对六关节角和 base 下的 tool0 位姿，刷新网页后加载检查目标。
搬动实机示教、重新使能后的保持行为及外部精度测量仍需操作者确认。
保留了操作者第五轴方向和预设速度修改，不将两项修改混入本轮提交，也不自动改写标定文件。

# Console 02 首轮实现与验收

控制基线：`v0.1.0-stage1`。前端分支：`feature/web-console-v2`。
计划先提交为 `704cee8`，随后实施。

## 已实现

- 自有蓝灰视觉、深色导航、常驻连接和软件停止、运行环境/状态/新鲜度/坐标标识。
- 六关节实时概览、TCP 位姿、任务状态及进度；过期数据不继续显示为实时角度。
- 单关节、多关节、输出轴三个目标页；多关节页保留关节/笛卡尔直线模式。
- 操作工作台、运行记录、开发诊断、方向测试分区；使用者/开发者视图。
- 实机/模拟/只读/commissioning 模式提示、故障和容差提示、原始坐标诊断和导出。
- HTML/CSS/控制逻辑/展示逻辑分离，静态资源本地加载；保留已有控制接口和请求门禁。
- 键盘焦点、控制标签、tab 语义和方向键切换；桌面、平板、手机布局。

参考文档与选择理由见 [计划](PLAN.md)。没有实现/声称三维预览、登录鉴权、程序编排或实时速度倍率。
显示模式不是权限隔离。软件停止不是物理急停，普通运动断线行为保持阶段一约定。

## 验证

| 检查 | 结果 |
| --- | --- |
| 离线响应式/交互 | 1440×1000、1024×768、390×844 四个视图无页面水平溢出；导航不发送命令 |
| 门禁与状态 | 过期、故障、只读、断线、软件停止路由及目标 tab 通过 |
| 离线诊断 | 原始反馈、完整错误、停止重试、最小速度、JSON 导出通过 |
| 完整 mock 链 | 单关节、多关节、输出轴目标、速度输入、停止、服务拒绝、任务终态通过 |
| 预设姿态 | 打包目标来源、1°/s 关节上限、任务互斥、取消、回零完成通过 |
| 笛卡尔 | 在 mock 上通过网页执行 Pilz LIN 完成，无实机笛卡尔操作 |
| commissioning | vcan0 实际单轴请求、选定电机、前后反馈、人工观察记录与 JSON 导出通过 |

实机服务在工作开始时停止。所有本轮运动测试仅使用 mock/vcan0；结束后测试服务全部停止。

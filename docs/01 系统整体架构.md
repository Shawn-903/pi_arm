# 01 系统整体架构

当前项目共有 10 个 ROS 2 包，作用如下：

| 包名 | 作用 |
| --- | --- |
| `pi_arm_description` | 保存 URDF/Xacro、STL 模型和机械臂几何描述 |
| `pi_arm_moveit_config` | MoveIt 运动规划、碰撞检测和 RViz 配置 |
| `pi_arm_transmission` | 六轴绳索运动学，负责关节角与电机输出轴角之间的转换 |
| `pi_arm_can` | SocketCAN 通信和 LK-TECH 电机 CAN 协议解析 |
| `pi_arm_hardware` | `ros2_control` 硬件插件，连接控制器、绳索运动学和 CAN |
| `pi_arm_interfaces` | 项目自定义的 ROS 2 消息、服务和动作接口 |
| `pi_arm_manager` | 上层运动与业务管理，例如接收运动命令、管理执行状态 |
| `pi_arm_websocket` | WebSocket 网关，让网页与 ROS 2 机械臂系统通信 |
| `pi_arm_validation` | 绳索运动学离线测试、数值验证和误差图生成 |
| `pi_arm_bringup` | 总启动包，一次启动硬件、控制器、MoveIt、WebSocket 等节点 |
